# Supply Chain Sales & Order Analysis

## Project Overview
This project analyzes sales and order data to evaluate sales performance, order quantities, and geographic distribution across different countries.

The project was completed as part of my Supply Chain Data Analytics learning journey using spreadsheet functions and Pivot Tables.

## Objectives
- Calculate total sales and order quantities.
- Analyze average, maximum, and minimum order quantities.
- Clean inconsistent city name formatting.
- Calculate the total number of orders.
- Compare order volumes and quantities across countries.

## Tools & Techniques
- Microsoft Excel / Google Sheets
- Spreadsheet formulas: `SUM`, `AVERAGE`, `MAX`, `MIN`, `COUNTA`, `PROPER`
- Pivot Tables
- Data cleaning and summarization

## Data Preparation
- Calculated sales and quantity metrics.
- Standardized city names using the `PROPER` function.
- Created a new `City_clean` column.
- Prepared the dataset for Pivot Table analysis.
